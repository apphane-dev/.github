# apphane

**a house for small, sharp tools**

Narrow-scope, open-source projects — each one a room in the house,
each one named in Turkish.

[apphane.dev](https://apphane.dev)

Every project below is deliberately small: one job, done carefully, with
visible lineage and a name you can hold onto. The Turkish word is the hook —
learn the room by learning the word.
